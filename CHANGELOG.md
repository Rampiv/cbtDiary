## 1.0.0
начало иислопа
### Features
- **Тёмная тема** — полная поддержка светлой и тёмной темы через CSS-переменные с сохранением в localStorage и Firebase
- **Автовыбор страниц** — автоматический выбор первой страницы при загрузке, кастомный select с названиями страниц
- **Авто-создание дневника** — шаблонная страница создаётся автоматически при первом входе
- **Страница когнитивных искажений** — отдельная страница /helpful/cognitive-distortions с 13 искажениями и примерами
- **Анализ когнитивных искажений** — мультиселект в ThoughtWorkPage для выбора искажений из списка
- **Политика конфиденциальности** — новая страница PrivacyPage с полной информацией о данных
- **Экспорт в DOCX** — выгрузка одной или всех страниц дневника в формате DOCX с профессиональным оформлением

### Redesign
- **ProfilePage** — редизайн с select для экспорта, переключатель темы, секция смены пароля
- **HelpfulPage** — карточки материалов с поиском/фильтром, адаптивная сетка
- **DiaryPage** — навигация по мыслям в select, fade-анимации переходов, стилизованные кнопки
- **Accordion** — тёмная тема, hover-эффекты, иконки
- **CustomSelect** — кастомный dropdown с hover-эффектами, active-состоянием, стрелкой и скроллом
- **Header** — навигация, кнопка выхода, тёмная тема

### Fixes
- **Бесконечная загрузка** — исправлен onValue listener, удалены блокирующие рефы
- **Page null** — добавлена проверка isPageLoading перед рендером
- **Circular dependency** — вынесен PagesContext в отдельный файл
- **Tiptap underline** — убрано дублирование расширения
- **Удаление страницы** — автоматическое переключение на последнюю созданную страницу
- **Создание страницы** — мгновенное переключение на новую страницу после создания

### Changes
- **Тёмная тема** — фон `#03002e`, акценты синие, белый текст
- **DOCX генератор** — таблица когнитивных искажений, форматирование полей label-value
- **Типы** — добавлены `title`, `cognitiveDistortions`, `distortionsExplanation` в DiaryPage
- **Архитектура** — Context-based state management, custom hooks, Firebase Realtime DB sync
