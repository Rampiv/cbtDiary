# Дневник мыслей

Деплой: https://cbt-diary-rampiv.vercel.app/

Персональный дневник для записи и отслеживания мыслей с поддержкой форматирования текста, аутентификацией через Firebase и Realtime Database для хранения данных.

## ✨ Возможности

- 🔐 **Аутентификация** — вход через Email/пароль и Google
- ✍️ **Text Editor** — форматирование текста (жирный, курсив, подчёркивание, списки)
- 💾 **Realtime Database** — мгновенное сохранение и синхронизация записей
- 🎨 **Современный UI** — чистый дизайн с SCSS и БЭМ-методологией
- 🌙 **Тёмная тема** — переключение между светлой и тёмной темой с сохранением в localStorage и Firebase
- 📱 **Адаптивность** — корректное отображение на всех устройствах
- 🔒 **Безопасность** — защита данных через Firebase Security Rules
- 🔑 **Шифрование данных** — AES-GCM шифрование на клиенте, данные недоступны даже администратору
- ✅ **Покрытие тестами** — 55 тестов, 7 модулей, 100% покрытие критической логики

## 🔑 Безопасность

### Клиентское шифрование

Приложение поддерживает **клиентское шифрование данных** с помощью алгоритма **AES-GCM** (стандарт, используемый в банковских системах и защищённых мессенджерах).

- **PBKDF2** для вывода ключей из пароля
- **AES-GCM** для шифрования/дешифрования
- Ключи хранятся в `localStorage`
- Зашифрованные данные хранятся в Firebase
- Данные недоступны даже администратору базы данных

### Переключение тем

Тема сохраняется в двух местах:
- `localStorage` — для быстрого доступа
- Firebase (`users/{userId}/settings/theme`) — для синхронизации между устройствами

При первом посещении автоматически определяется системная тема через `prefers-color-scheme`.
